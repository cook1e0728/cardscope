## 已檢查、沒問題

- 鍵盤：skip link（跳到主要內容）、Tab 順序合理、所有互動元素焦點外框可見（實測 outline 3px 對比色）。
- 詳細頁對話框：Enter 開啟後焦點進入關閉鈕、Tab 40 次不外洩、Esc 關閉、焦點回到原本的卡片開啟鈕、網址不殘留 `card`；`role=dialog`、`aria-modal`、`aria-label` 齊全。
- 我的收藏（原生 `<dialog>`）、篩選與排序面板、首次導覽（Esc 可略過、焦點陷阱）：開啟、Tab 迴圈、Esc 關閉、焦點回觸發鈕皆正常。
- `prefers-reduced-motion`：懸停傾斜／淡入以 `no-preference` 閘門包住，另有使用者「暫停動態」開關，不是整站 0.01ms 一刀切。
- 響應式：375／768／1024／1440 與 200%（720px）、400%（360px）縮放皆無整頁橫向溢出；橫向捲動只出現在刻意的軌道（系列列、分頁）；375 寬度首次導覽卡片完整可見（早先無頭 500px 最小寬度造成的裁切是工具假象）。
- 圖片 alt：全站 `<img>` 皆有 alt 屬性（卡片縮圖空 alt、由外層按鈕 aria-label 說明）；卡圖 `loading=lazy` 比例高（185 張中 158 張）。
- 對比：純色背景文字掃描（首頁、系列頁、狀態頁、詳細頁）沒有低於 AA 的項目（漸層／圖片背景未掃）。
- 空狀態：空搜尋（含兩個建議）、收藏為空（「還沒有收藏」＋匯入／探索）、無卡片文字（「資料來源沒有提供…不以自行生成內容補空白」）、圖片待補（「這張卡尚未收錄可公開顯示的圖片」）、資料不足價格（「不以假價格補空白」）文案清楚。
- 搜尋：中、英、卡號（OP-17-118）、表情、`<script>` 輸入皆回應且已跳脫；`?q=` 可分享並還原；搜尋結果含總數與「已顯示 N 筆」。
- SEO 基礎：卡片／系列頁有獨立 title、description、canonical、og:*、twitter、JSON-LD；不存在的卡／系列回 404＋`noindex`；robots.txt（允許 /api/images/、封鎖 /api/、附 sitemap）；sitemap index 分 pages／series（1,401）／cards-1（40,000）／cards-2（25,756）皆 200、格式正確；`og:image` 預設圖 200。
- PWA：manifest、192／512／maskable 圖示、離線圖、64px favicon 皆 200；真實瀏覽器已註冊 SW（scope `/`）；sw.js 邏輯僅快取同源 GET 外殼、略過 `/api/` 與第三方卡圖。
- API 邊界：`game=bogus` 回 400 中文訊息、未知卡回 404 中文訊息、未知系列回空陣列。
- 資料抽樣（DB 唯讀，實體卡層）：航海王亞洲／台版 4,914／4,915 張圖、中文名、稀有度皆 100%；排球少年、芙莉蓮圖與稀有度 100%；寶可夢台版缺圖僅 4 張、中文名 100%；遊戲王缺圖 164 張（0.4%）；圖片網址抽樣 98 張（七個 IP／地區各 14）皆可載入，無孤兒（`orphans` 全 0）。

- 第一個「高」項（系列深連結）影響 sitemap 所有非預設地區系列，也影響使用者分享的系列連結（本報告只驗證了 `?game=&series=` 這種無 region 的格式，沒有逐一驗證站內點擊系列後產生的網址是否一律帶 region）。
