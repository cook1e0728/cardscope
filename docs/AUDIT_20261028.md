## 其餘（細節見各報告）

- **資安 中**：13 處端點直接回 `e.message`（可能洩漏 PostgREST 片段）；`scripts/preview-proxy.mjs` 綁所有網卡且無白名單，執行期間同網段可讀 `.env.local`。
- **BUG 中／低**：篩選摘要「稀有度待補」數字是全系列的；搜尋 `.`／`_` 回 159 張樣本卡；含 BOM 的 JSON 備份匯入失敗；`today()` 用 UTC，台灣發售日 00:00–08:00 仍標即將發售；放大檢視按方向鍵會換掉背後的卡；遊戲王 925 張卡級稀有度不在任何印刷中；`OP05-001 R` 0 筆無建議。另有 7 個未重現疑點。
- **完善度 中**：未知路徑回 JSON 而非 404 頁；首頁／遊戲頁缺 canonical 與 og:image；API 失敗約 10 秒才露出英文「Failed to fetch」且無重試；遊戲王卡號欄顯示 passcode、681 筆 `unspecified` 版本；價格分頁分不出「此 IP 無價格來源」與「此卡暫無價格」；日版 8,461 張 `NONE` 在詳細頁與卡表說法不一；美版稀有度混用來源原字。低嚴重度 10 項。
- **效率 其他**：`/api/cards`、`/api/search`、`/api/cards/:id` 回 `no-store`，可改 `max-age=60`＋stale-while-revalidate。報告另列可刪除清單與重複實作。注意 `browse_cards_priced`／`browse_cards_json` 是進行中的價格排序工作，不是死碼。
- **體驗 中**：桌面看不到手機的「稀有度直選」、美版稀有度十多種寫法、手機卡格 10px 字；頂欄與 dock 所在位置提示不一致；「版本」一詞指三件事；手機首頁 7 個「新發售」紅標；「同名推導」說明只在 tooltip。
