# 首頁桌面第一屏改為「夜間展示櫃」

**狀態：已採用（2026-10-22，使用者從 5 版桌面預覽中選定第 3 版）。取代 ADR 0048 中桌面版「活頁打孔卡紙＋雙色書脊」的部分；吉祥物、標題文案與漂浮動畫沿用 ADR 0048。**

使用者要求依 `impeccable` 與 `ui-ux-pro-max` 兩個 Skill 重做首頁介面並提供 5 版預覽（1 目錄頁、2 搜尋工作台、3 夜間展示櫃、4 Bento、5 實體卡感），以 `?preview=1～5` 在正式資料上比較後選定第 3 版。兩個 Skill 只讀其規則，未在本機執行其附帶腳本。

決定（`look-clean.css` 末段，只作用於 ≥761px；手機首屏不變）：

- **深靛色帶**：首頁第一屏（`.hero`，含遊戲入口、版本、最新系列與單卡推送）為一整片 `#1B1733` 圓角 24px 色帶，頂欄同色系 `#16132A`，頁面其餘部分維持暖石色。色調取自吉祥物插畫的星空，讓插畫（260px、1px `#3B3560` 外框、帶位移的陰影）成為展示品。
- **拿掉**：打孔紙圖案、12px 側邊書脊（impeccable 禁止 >1px 的側邊色條）、遊戲入口與最新系列外層的卡中卡框。
- **字與色**：標題 `Chiron Hei HK` 700（加入 Google Fonts 連結）；正文 `#C9C1DA`、標題 `#F6F1E6`，對深底皆 ≥4.5:1；搜尋鍵與選中狀態用金色 `#E7BA4C`（深字），焦點環金色。
- **遊戲入口**：各 IP 標誌放在米白小牌（`#F6F1E6`）上，維持原色標誌的辨識度；選中為 2px 金色外框＋標籤變亮，不只靠顏色。

## Consequences

- 首頁桌面版沒有側邊書脊；ADR 0048 的活頁打孔描述只剩手機版適用（手機首屏原本就無書脊與打孔）。
- 預覽開關與 `home-preview.css` 已移除；5 版截圖只留在本機 `docs/design-previews/home-20261022/`（未提交）。
