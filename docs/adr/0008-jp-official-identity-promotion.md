# 日版卡以官方卡片頁作為身分驗證依據

ADR 0006 只讓「連結到台版」的日版 Card 升為 `verified`，並以「需要爬取官方網站」為由不採用官方核對；ADR 0007 實查後該理由不成立。決定（2026-10-02 使用者同意）：日版 Card 若在 pokemon-card.com 公開卡片搜尋的詳細頁上，系列標記、卡號與日文名（NFKC 正規化後）三者都與資料庫相同，即視為身分已由可靠來源確認，從 `pending` 升為 `verified`。其 Printing 依既有規則：稀有度已知為 `verified`，否則為 `incomplete`。

與 ADR 0006 相同：只升不降、每次最多 100 張、追加式稽核，並記錄所依據的官方 card ID。官方頁只提供身分證據；名稱相似、官方搜尋結果的排序或縮圖路徑都不算證據，只用來找候選頁。

## Consequences

- 沒有台版的系列（SVLN、SVLS、SVK、SV11B、SV11W 等）也能升級，`pending` 會大幅減少；仍為 `pending` 的卡代表官方頁找不到或資料不一致，值得逐筆查看。
- 官方頁事後更動不會讓已升級的卡自動降級；若發現錯誤需另立決策。
