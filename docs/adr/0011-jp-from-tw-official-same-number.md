# 日版卡以台灣官方同系列同卡號資料補中文名與稀有度

部分系列在 Source archive 沒有台版，所以日版卡無法依 ADR 0003 連結台版、也沒有官方中文名（SV11B 64、SV11W 77 張只有推導或沒有中文名），牌組 SVK 的稀有度也無從得知；但台灣官方卡片搜尋其實收錄了 SV11B、SV11W、SVK。決定（2026-10-02，使用者授權照建議執行）：日版 Printing 可直接採用台灣官方同系列代碼、同卡號那張卡的中文名與稀有度，不需要資料庫中先有台版 Card。

保護措施：

- 每個系列先做對齊檢查：該系列中，日版已有可靠中文名（台版官方或同名推導）或已有稀有度（日本官方）的卡，與台灣官方同卡號的值必須全部一致；任何一筆不一致，整個系列都不採用（SV-P 曾有日台編號錯位）。
- 同卡號在台灣官方有多個版本時，中文名與稀有度都必須一致；系列歸屬以官方系列篩選清單為準，規則同 ADR 0010。
- 只填空值（中文名、稀有度各自判斷），不覆寫；中文名依據記為 `tw-official-same-number`，不建立 Canonical card 連結（連結仍只依 ADR 0003）。
- 交易式函式、dry-run、重播零異動、追加式稽核。

## Consequences

- 台版有收錄但 Source archive 沒有的系列，日版也能拿到官方中文名；這些名稱是官方名，不是 Derived name，但因沒有 Canonical card 連結，台版 Printing 不會出現在日版詳細頁。
- 是否把這些台版卡正式匯入為台版 Printing，是另一個決定。
