# 台版稀有度以台灣官方卡片搜尋補齊，並記錄無標記

台版 Printing 7,436 筆中有 6,634 筆沒有稀有度（83 個系列，Source archive 的 zh-tw 沒有值）。台灣官方卡片搜尋（asia.pokemon-card.com/tw）的詳細頁沒有稀有度欄位，但搜尋可依稀有度篩選，選項包含「無標記」。試查 SV8a：台版官方把一般卡歸為「無標記」（288 筆），RR 35、SAR 33、SR 12、UR 5、ACE 8；日本官方頁對同一批卡沒有圖示，原因就是卡面沒有記號。決定（2026-10-02，使用者授權照建議執行）：

- 來源：台版稀有度取自台灣官方卡片搜尋的稀有度篩選結果；身分以詳細頁的系列標記、卡號與中文名核對，三者一致才採用（名稱比對前去掉 Source name markup；官方標題省略卡面括號小字時比照 ADR 0007 視為一致，如「妮莫（過去）」對「妮莫」）。系列歸屬以官方系列篩選（expansionCodes）清單為準，系列標記圖檔名只做一致性檢查（命名不一，須以獨立字詞含系列代碼）。官方頁沒有卡號的基本能量無法對應，維持未知。只取文字事實，不取圖片；抓取規則同 ADR 0007（單一連線、間隔至少 1.5 秒、非 200 即停、證據存檔）。同一卡號在官方有多個版本時，所有版本的稀有度必須相同，否則 Quarantine。
- No rarity mark：官方明確歸為「無標記」時，記為稀有度代碼 `NONE`（畫面顯示「無標記」），視為已知；排序放在最低。只有官方明確給出「無標記」才寫入 `NONE`，頁面沒有資訊仍是未知（ADR 0007 的規則不變）。
- 日版沿用：日版官方頁沒有稀有度圖示、且該日版 Card 已依 ADR 0003 連結到同系列同卡號的台版 Card，而該台版 Printing 已由台灣官方取得稀有度（含 `NONE`）時，日版採用同一值，並記錄依據為台灣官方。日台同系列同卡號是同一張卡面設計，連結本身已由 Provider ID、卡號與名稱驗證。
- 寫入只填空值，不覆寫；交易式函式、dry-run、重播零異動、追加式稽核，與既有日版函式相同。台版既有稀有度若與台灣官方不同，只記錄差異，修正另行決定。

## Consequences

- 稀有度篩選會多出「無標記」；完整度統計把 `NONE` 算為已知。
- 台灣官方未收錄的系列或卡號仍是未知。
