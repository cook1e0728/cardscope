# 台版系列標記與代碼不同時，以逐系列別名接受（SVOM）

台灣官方卡片搜尋中，「挑戰牌組 瑪俐的莫魯貝可&長毛巨魔ex」（系列篩選代碼 SVOM）的 23 張詳細頁，系列標記圖檔名全部是 `SVO_ex`（少了 M）。ADR 0010／0015 要求標記以獨立字詞包含系列代碼，所以 SVOM 在 2026-10-03 整系列未匯入。查證（官方快取 `docs/evidence/pokemon-tw/official-rarity-20261002.json`）：125 個官方系列代碼中沒有 `SVO`；`SVO_ex` 只出現在 SVOM 清單，且 SVOM 清單沒有其他標記；同系列的 SVOD 清單全為 `SVOD_ex`。

決定（2026-10-04，使用者授權照建議執行）：

- ADR 0010 已定系列歸屬以官方系列篩選為準、標記只做一致性檢查，因此標記命名差異可由**逐系列明列的別名**接受（`SVOM → SVO`），比對方式與代碼相同（獨立字詞、可接 F／OUT）。
- 不採「標記為代碼前綴即可」的通用規則：那會讓 SV4 對上 SV4a，正是既有比對刻意排除的情況。
- 別名成立條件，由計畫產生器強制：該系列清單的每一筆標記相同，且同一標記不出現在任何其他系列清單；不成立則整系列中止。
- 其餘規則不變：無卡號的基本能量隔離；卡號超出分母（022/021）照收；稀有度依 ADR 0010（官方「無標記」為 `NONE`）。
- 日版連結沿用 ADR 0011 的卡號對齊；日台卡號排列不同時不連結（比照 SVOD）。

## Consequences

- 2026-10-04：台版 SVOM 22 張匯入（全為 `NONE`），基本【惡】能量隔離；重播零異動。日版 SVOM 20 張的卡號排列不同（日 009 能量回收器、台 009 吉雉雞ex），不連結。
- 之後若再遇到標記與代碼不同的系列，須逐一查證並加入別名清單，不會自動放寬。
