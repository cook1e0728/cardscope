# 日版同名推導改以資料庫中的官方中文名為證據，不限世代與來源

ADR 0004 的跨系列同名推導只限朱紫世代、只限 `tcgdex-ja` 系列，證據是 Source archive 的對照表。2026-10-03 日版缺中文名 758 張：日本官方來源系列（ADR 0012）246 張（多為台版未收錄的 SR／HR／UR、S4a 色違卡），`tcgdex-ja` 512 張（SM 世代 403 張等）。這些卡的日文名，多半已有其他日版卡帶著台灣官方中文名（依 ADR 0003 連結的 `tw-official`，或 ADR 0011 的 `tw-official-same-number`）。

決定（2026-10-03，使用者授權照建議執行）：日版卡沒有中文名時，若資料庫中**日文名完全相同**的日版卡已有官方依據的中文名，且這個日文名在所有官方依據的日版卡中只對應**唯一一個**中文名，就採用為 Derived name：

- 依據記為 `derived-cross-series`（介面同樣標示「同名推導」），並記錄 `nameZhSourceCardId`（被引用的官方依據日版卡）與 `nameZhRule: 'adr-0013'`。
- 不限世代、不限來源（`tcgdex-ja` 或 `pokemon-card-official-jp`）；只填空值；不連結 Canonical card。
- 資料庫函式逐張重新驗證：目標卡為日版且中文名為空、日文名一致；被引用的卡為日版、日文名完全相同、中文名一致且依據為官方；同一日文名沒有任何官方依據的日版卡帶著其他中文名。每次最多 100 張、dry-run、重播零異動、追加式稽核。

日文名比對先做 NFKC 並去掉空白（2026-10-03 補充：SM 世代寫「アローラロコン」，之後寫「アローラ ロコン」，空白不改變名稱）；不採用「去掉括號附註後相同」的寬鬆比對：日本官方標題會省略括號附註（博士の研究 對 多位博士）。

## Considered Options

- 沿用 ADR 0004 的 Source archive 對照表：S、SM 世代封存中沒有足夠的台版資料，而且證據在資料庫外。
- 不推導、維持空值：名稱缺口集中在高稀有度異圖與色違卡，這些卡的寶可夢名稱與同系列一般卡相同，留空對使用者幫助不大。

## Consequences

- 預估可補 508 張（官方來源 235、`tcgdex-ja` 273）；日文名對應多個中文名者（如 博士の研究）維持空值。
- 中文名來自台灣官方名稱，但這張卡本身未經台灣官方確認，因此仍是 Derived name，不是身分證據。
- ADR 0004 的朱紫世代規則仍有效；本決定是另一條證據來源，兩者都只填空值。

## 補充（2026-10-11）：只差寫法的官方中文名視為唯一

- 使用者授權照建議執行。同一日文名的官方中文名，若去掉下列差異後完全相同，就視為唯一：全形半形（NFKC）、零寬字元、Source name markup（`<X的>` 的角括號、`[支援者]` 等方括號附註），以及結尾的括號人名（`博士的研究（山梨博士）`、`老大的指令（坂木）`）。比照 ADR 0007／0011 名稱比對時「只差結尾括號附註不算不一致」。
- 採用的寫法必須是去掉差異後的形式，而且本身是某張卡的官方原字串（例如 `博士的研究`、`謎擬Q`）；帶附註的寫法會被拒（`not-plain`）。只差空白位置（`月月熊 赫月 ex`／`月月熊 赫月ex`）仍視為不唯一。
- Migration `20261011060000_pokemon_jp_derived_names_name_variants`：新增 `private.zh_official_name_key`，推導函式的唯一性改用它比對。結果 92 張（博士的研究 48、老大的指令 34、其餘 10），兩批寫入＋重播零異動；候選 `docs/evidence/pokemon-jp/derived-names/adr-0013-candidates-name-variants-20261011.json`。推導每次約 12 秒（46 張），單批勿超過約 50 張以免超過連線上限。
- 同日另修：TCGdex 封存把日版 M6 098／099 的日文名對調（日本官方 098 ポケモンキャッチャー、099 とくちゅうチョッキ），使「ポケモンキャッチャー」看似對到「訂製背心」而被判不唯一。更正兩張卡與作品層的日文名（舊值記在 `nameJaBefore`）後，ポケモンキャッチャー 54 張推導為「寶可夢捕捉器」。全面比對 6,907 張日版卡與日本官方快取，只有這一對不一致。
