# 日版特典卡系列（SV-P、M-P）以日本官方卡片搜尋匯入

日版特典卡一直未匯入：Source archive 的 SV-P 日台編號錯位（ADR 0004），M-P 比照不匯入，且特典卡號格式未定。日本官方卡片搜尋的特典清單格式其實很乾淨：詳細頁系列標記為 `SV-P`／`M-P`／`S-P`，卡號為系列內編號（如 `259`，斜線後是系列代碼而非總數），沒有稀有度圖示。決定（2026-10-04，照建議自動執行；AGENTS 規定的 Sol 裁決在此環境不可用）：

- 依 ADR 0012 匯入，系列代碼允許 `-P` 結尾（`^[A-Za-z0-9]+(-P)?$`，migration `20261004010000`，其餘規則不變）。ID 為 `pokemon-official-ja-sv-p`、`pokemon-official-ja-sv-p-259`。
- 系列日文名取官方卡片搜尋頁擴充包選單的商品名（`ポケモンカードゲームスカーレット＆バイオレット プロモカード`、`ポケモンカードゲーム MEGA プロモカード`）；特典系列沒有單一發售日，留空。S-P 在官方選單與 Source archive 都沒有日文系列名；之後查到官方卡片搜尋以 `pg=S-P` 查詢時 `searchCondition` 回傳「ポケモンカードゲームソード&シールド プロモーションカード」，以此為系列名一併匯入（2026-10-04）。
- 稀有度：官方頁沒有圖示，依 ADR 0007 維持未知（不以 `Promo` 推定），Printing 為 `incomplete`。同卡號在官方有多張時整號 Quarantine（ADR 0012）。
- 中文名先試 ADR 0011（對齊不通過即整系列拒絕，不連結），再依 ADR 0013 由資料庫中的官方中文名推導。

## Consequences

- 特典卡進入日版卡表與搜尋；與台版、美版特典不連結。
- 若日後要標示特典的「PROMO」記號，需另立規則，不沿用稀有度欄位。
