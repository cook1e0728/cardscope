# 日版既有稀有度依官方卡片頁修正

ADR 0007 原本只補空值、不覆寫。試跑發現系統性錯誤：Source archive（TCGdex）以英文版分類標日版稀有度，`Ultra Rare` 被存成 UR，但日版卡面與官方頁是 SR（SV6a 080–086）；日版的 UR 是金卡。決定（2026-10-02 使用者同意）：日版 Printing 的既有稀有度，若官方詳細頁有可對映的稀有度圖示、且系列標記、卡號、日文名都相同，而值與資料庫不同，就改為官方值。官方頁是卡面的一手來源，Source archive 是轉譯，以官方為準反而更接近實物。

保真措施：只改有官方證據的列；原值與原依據寫入 Printing 的 metadata（`rarityBeforeOfficial`），稽核表保存修改前後快照；寫入時要求資料庫現值仍等於計畫中的舊值，避免覆蓋別人剛改的資料；Card 的稀有度同步修正；只改日版（`tcgdex-ja`），台版、美版不動；官方頁沒有圖示（ACE SPEC、牌組）或圖示不認得時不改。

## Consequences

- 日版 UR／SR 的數量會大幅變動，稀有度篩選與排序隨之改變；這是修正，不是新資料。
- 台版、美版的 UR 仍是各自來源的值；跨地區合併的作品層若混有不同地區的稀有度，各 Printing 各自顯示，不互相覆蓋。
