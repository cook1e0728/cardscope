# 2026-10-23 全站審查後的強化與擴充決策

**狀態：已採用（2026-10-23）。使用者要求從功能性、使用者體驗、方便性、IP 完整度、比價、伺服器性能與穩定度多方面審查並強化，且「grill me、自動照建議進行」。以下 Q1–Q12 都照建議答案執行；Q7（新 IP）涉及接受新的授權風險，依產品計畫「自主決策邊界」等待使用者明確回覆。**

審查方式：4 位只讀審查員平行實測正式站（功能體驗、IP 完整度、比價、效能穩定），另 1 位研究新 IP 資料來源；主管逐項核對證據後分批修正、測試、上線。完整發現與處理結果見 `docs/AUDIT_20261023.md`。

## 決策

- **Q1 先修後擴充**：先修高、中嚴重度問題（崩潰、資料外洩、錯誤價格、資料錯誤），再做新功能。
- **Q2 維持零花費**：Render、Supabase 皆免費方案；資料庫內部紅線 450 MB（上限 500 MB），每個新 IP 預算 ≤ 30 MB；容量不足先瘦身，不升級。
- **Q3 新 IP 一次一個**，做完整後再決定下一個。
- **Q4 第一波新功能**：系列集卡進度、收藏匯出／匯入、加到主畫面（PWA）。不做價格提醒（需通知基礎設施）與牌組編輯器（偏離定位）。
- **Q5 暫不做登入與雲端同步**：收藏仍存在使用者瀏覽器，以匯出／匯入解決換裝置。
- **Q6 不記錄使用者行為**（含零結果搜尋詞），維持產品計畫原則。
- **Q7 新 IP（2026-10-30 使用者明確同意收錄，`risk-accepted`）**：以官方繁中站 `dbs-cardgame.com/fw/asia-tc/cardlist/` 為來源，遊戲 id `dragonball-fw`，地區 TW，日文名稱取自官方日文站同卡號；卡圖直接引用官方站。原始研究：研究推薦七龍珠超 Fusion World（官方繁中站、靜態頁、繁中站卡圖為日文印刷）。官方頁尾「未經許可禁止使用」，收錄等同再接受一次 `risk-accepted`，須使用者明確同意。萬智牌 Scryfall 條款清楚但英文約 10.5 萬張，超出容量，只能限縮（例如只收繁中印刷）。
- **Q8 遊戲王中文名**：沒有官方繁中來源。卡名直接顯示原文名（拿掉「中文名稱待補｜」前綴）；另整理約 200 張熱門卡的台灣常用叫法，只作搜尋別名，不寫入 `name_zh`、不當官方名稱顯示。
- **Q9 美版寶可夢中文名**：寶可夢角色卡沿用資料庫內官方繁中物種名＋後綴（依全國圖鑑號，只填空值、`metadata.nameZhBasis` 記依據）；訓練家、能量卡維持英文。日版同理推導「去掉後綴後日文名只對應唯一官方中文名」的卡（另見該次 ADR）。
- **Q10 芙莉蓮卡圖**：不轉存到自己的空間（超出「只外連」的風險範圍）；卡圖首次失敗隔 1.5 秒重試一次，仍失敗顯示「圖片待補」。
- **Q11 卡牆參考價與價格排序**：只有寶可夢有可靠的每日 Cardmarket 快照，卡牆顯示「Cardmarket 參考」原幣價與觀測日（超過 7 天不顯示），並開放依參考價排序；其他 IP 維持隱藏。
- **Q12 跨版本價格對照**：詳細頁「價格」分頁並列同作品各地區版本的價格（每列只對應該 printing，標來源、種類、原幣、台幣換算、觀測日），不計算「哪裡最便宜」、不加總。

## 同輪的技術決定

- 伺服器：請求處理的例外只讓該請求失敗（壞的 `%` 編碼回 400），加 `unhandledRejection` 紀錄；靜態檔改白名單（根目錄 .js/.css、index.html、assets、前端讀的兩個 data 檔、manifest）；統一安全標頭；搜尋字數 ≤ 100、`/api/cards` offset ≤ 200,000。
- 快取：`/api/catalog`、`/api/products`、`/api/catalog/coverage` 加 `public, max-age=60, stale-while-revalidate=300`；首頁覆蓋率報告共用一次請求。
- 比價：遊戲王價格改用該 printing 的卡號＋稀有度精確配對 YGOPRODeck set price，配不到不顯示（不再以跨版本最低價冒充）；來源名稱依實際有資料者顯示；收藏參考價超過 7 天不計入。
- 版本標示：航海王台灣官方站的卡為日文印刷，介面稱「亞洲日文版」（資料層 language 未改）。
- 收藏：數量 > 0 即收藏，☆ 為快速鍵，舊星號資料一次遷移成數量 1。
- 搜尋：CJK 空白容錯、卡號分隔符號正規化、只打稀有度代碼給提示、零結果以 `pg_trgm` 給相近卡名、搜 IP 名稱提供前往圖鑑。
