# 三版卡圖補齊：英文官網與遊戲王日文官方資料庫，使用者接受未確認條款的風險

**狀態：已採用（2026-11-04 使用者要求「全部卡圖先補齊（台／美／日三版），不需再詢問」；2026-11-05 對遊戲王日版與航海王美版回覆「都收 開始做」）。**

既有的風險接受只涵蓋特定網域：ADR 0027 航海王亞洲英文與繁中卡表、ADR 0034 排球少年與芙莉蓮日文卡表、ADR 0052 Q7 七龍珠超繁中卡表。為了補齊美版與日版，這次擴大到以下來源：

- **Weiß Schwarz 英文官網** `en.ws-tcg.com`（只取作品編號 183，葬送的芙莉蓮）：英文版本掛到同卡號的日版卡，英文獨有的 PE 推廣卡另建卡（2026-11-05 上線）。
- **七龍珠超 Fusion World 英文卡表** `www.dbs-cardgame.com/fw/en/`（2026-11-04 上線，同一網域）。
- **航海王美國英文官網** `en.onepiece-cardgame.com`：美版版本（region US）。
- **遊戲王官方卡片資料庫日文版** `www.db.yugioh-card.com/yugiohdb/`（request_locale=ja）：日版版本（region JP）、日文卡名、日版收錄包；以 YGOPRODeck 的 `konami_id` 對到既有卡。

決定：

- **範圍**：只收文字事實（卡號、名稱、稀有度、收錄包、發售日）與官方圖片網址；圖片只外連，不轉存。
- **條款依據**：仍沒有書面許可或明確條款，`metadataCollection` 記為 `risk-accepted`，不表示已取得授權。en.ws-tcg.com 的 robots.txt 只禁止 `/wordpress/wp-admin/`；en.onepiece-cardgame.com 的 robots.txt 回 404。
- **只新增**：既有列不改，空欄位（英文名、日文名）才補。
- **頻率與禮貌**：與既有官方同步相同：每 72 小時最多一次、單一連線、請求間隔至少 1.1 秒、非 200 重試兩次後停止，解析到 0 張即整輪不寫入。
- **撤回**：`collectionEnabled` 改回 `false` 即停止；已寫入的資料保留。

## Consequences

- 遊戲王繁中版沒有做：官方資料庫的語系有 ja、en、ae、cn、ko 等，沒有繁中，查不到官方來源。
- 美版與日版版本若掛在既有系列下（芙莉蓮、七龍珠），遊戲頁的地區按鈕不會多出該地區，只在詳細頁與搜尋出現。
