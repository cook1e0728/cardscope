# 日版稀有度以日本官方卡片搜尋補齊

日版 Printing 有 707 筆稀有度為空（328 筆屬已驗證 Card、379 筆屬待核 Card），原因是 Source archive（TCGdex）本身就是空值：多為各彈卡號超出系列張數的高稀有卡、SV8a 幾乎整彈，以及 88 筆牌組商品（SVK、SVLN、SVLS）。決定：以 pokemon-card.com 的公開卡片搜尋作為日版稀有度來源，只取文字事實（系列標記、卡號、日文名、稀有度圖示），不取、不轉載圖片。官方是最權威的來源，也能糾正 Source archive 的錯標（如 SV6a 092–094 的 `Mega Hyper Rare`）。

規則（2026-10-02 與使用者確認）：

- 範圍：所有稀有度為空的日版 Printing，不論所屬 Card 是否已驗證；稀有度屬於 Printing，與名稱或連結無關。
- 對應：官方詳細頁的系列標記與卡號，必須與 Printing 的系列代碼、卡號完全相同，且日文名一致（NFKC 正規化後比較；官方標題省略卡面括號小字時，資料庫名稱等於官方標題加一組全形括號說明也算一致，如「ボスの指令（ゲーチス）」對「ボスの指令」，2026-10-02 使用者同意）；任何一項不符即 Quarantine，不寫入。名稱相似不作為對應依據。
- 寫入：只填空值，不覆寫既有稀有度；官方與既有值不同時只記錄差異。Card 的稀有度同時填入，維持 Card／Printing 一致。
- 對映：官方圖示 `ic_rare_<代碼>` 轉成資料庫既有的同名簡寫代碼（C、U、R、RR、RRR、AR、SR、SAR、UR、HR、S、SSR、K、ACE、MUR、BWR、CHR 等），圖示檔名的 `_c` 後綴（`u_c`、`sr_c`、`ur_c`）去掉後再對映；SV6a 057–064 的 `u_c` 與既有 U 7/7 一致。不認得的圖示一律 Quarantine。
- 無圖示：官方頁沒有稀有度圖示時 Quarantine，維持「稀有度未知」。原本打算記為 No rarity mark，但實查 SV6a-063（ACE SPEC，卡面有稀有度）官方頁同樣沒有圖示，所以官方頁無圖示不能證明卡面無記號；牌組商品（SVK、SVLN、SVLS）因此暫不處理，No rarity mark 仍需其他證據。
- 抓取：一般 GET、單一連線、每次請求間隔至少 1.5 秒，任何非 200 回應即停止並記錄，不重試轟炸、不繞過限制；所有回應摘要存成證據檔。
- 寫入走交易式函式：dry-run、digest 重播零異動、追加式稽核，與既有日版函式相同。

## Considered Options

- 等 TCGdex 上游補齊：沒有時程，SV8a 自 2026-09-24 起即缺，且無法修正錯標。
- 其他第三方資料庫：權威性不如官方，仍需再對官方核對。

## Consequences

- ADR 0006 曾以「需要爬取官方網站，違反不繞過反爬的原則」否決官方核對；實查官方站沒有 robots.txt，卡片搜尋本身提供公開 JSON 端點，低速讀取不涉及繞過或付費，該理由不再成立。0006 的升級規則本身不變；官方卡號證據能否讓待核 Card 升級，另行決定。
- 主方案中「官方網站只作驗證或外連」仍適用於圖片；本決定只擴大到文字事實。
- 劍盾世代出現官方圖示 `ic_rare_csr`，新增稀有度代碼 CSR（Character Super Rare，排序在 SR 之後），比照 ACE 的新增方式。MEGA 世代出現 `ic_rare_ma`（台灣官方篩選亦有 MA），新增 MA（Mega Attack Rare）；依 MEGAドリームex 官方卡號區段（SR 214–222 < MA 223–232 < SAR 233–249）排在 SAR 之後。初次誤排在 RR 之後，已以新增 migration 更正。
- 官方與既有值的差異只記錄、不覆寫。試跑即發現系統性差異：SV6a 080–086 官方為 SR，資料庫沿用 Source archive 的 `Ultra Rare` 存成 UR；日版的 UR 是金卡（如 092–094）。既有日版 UR 是否全面改為 SR，屬於覆寫既有資料的另一個決定。
