# ADR 0056：重新設計 v2（B′：展示首頁＋卡冊內頁、紙感按鈕）

日期：2026-11-12　狀態：已採納（使用者 2026-11-11「定 B′」、紙感按鈕；2026-11-12「照建議開始」＝`docs/REDESIGN_PLAN.md` 第 5 節決定 3–11 全照建議）

## 決定

- **骨架 B′**：首頁維持滿版夜空展示（ADR 0048／0050／0051 不推翻）；遊戲頁、搜尋結果、收藏改用「左側欄（遊戲→版本→系列→商品）＋卡牆＋右側詳細資料側板」。手機側欄為底部拉起的選單，詳細資料全螢幕。
- **全站設計規則**以 REDESIGN_PLAN 第 3 節為準：底色三層（頁面 `#F8F5EE`、內容 `#FFFFFF`、凹陷 `#EFEAE0`）、框線只給可點可輸入的東西（1px `#E7E1D4`）、字四級（20–28／15–16／13／12px）、按鈕三種（主要、次要、文字）高 44px、紙感質感、按下縮 97%、介面動畫 ≤300ms。
- **說明句與警語收進 ⓘ**；法律與誠實原則要求的那一句（如「不是成交價」）保留一句短的。
- 決定 3：收藏星號不放卡圖上，放在卡名那一行右邊（手機放卡號那一行右邊）。
- 決定 4：漲跌榜與時事搬到獨立「行情」頁，頂欄仍三顆鈕。
- 決定 5：詳細資料不分頁，資訊與價格連續排。
- 決定 6：手機一排 3 張。
- 決定 7：收藏頁用卡牆版面，進階功能收進側板與「管理」選單。
- 決定 8：實體商品分類放進側欄。
- 決定 9：手機只留底部導覽列；2×5 快速探索格與稀有度快選盤由側欄選單與工具列取代。
- 決定 10：已收藏的卡顯示「− 數量 ＋」，減到 0 即取消（有品況或備註時先確認）。
- 決定 11：兩顆「只看…」合成一組「收藏狀態（全部／已收藏／還缺）」。

## 取代

- PRODUCT_PLAN 第 4 節「詳細頁分頁為資訊／價格／走勢」、第 5 節的紙色底 `#EFEAE0` 作為頁面底與邊框 `#D9D1C0`：分支 `redesign-v2` 合併後失效，改依本 ADR。合併前 main 照舊。

## 執行

分支 `redesign-v2`，六個階段（REDESIGN_PLAN 第 6 節），每階段給使用者預覽，同意後才合併 main。
