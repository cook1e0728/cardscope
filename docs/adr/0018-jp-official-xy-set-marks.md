# 日版 XY 世代以官方系列標記（含連字號後綴）匯入

Source archive 對 XY 世代只有 CP1、CP2 有日文卡名；先前以 `XY7` 等代碼查日本官方卡片搜尋只得到少量卡，判斷為官方清單不完整。逐一查官方商品後發現：XY 世代詳細頁的系列標記其實帶後綴（`XY1-Bx`、`XY5-Bg`、`XY6-B`、`XY7-B`、`XY8-Bb`、`MMB-S` 等），以這些標記查詢的張數與商品內容一致（如 `XY7-B` 84 張，`XY7` 只有 11 張是別的再錄）。決定（2026-10-04，照建議自動執行；AGENTS 規定的 Sol 裁決在此環境不可用）：

- 依 ADR 0012 匯入，系列代碼即官方系列標記原字串，允許一段連字號後綴（`^[A-Za-z0-9]+(-[A-Za-z0-9]+)?$`，migration `20261004020000`，其餘規則不變）。ID 為 `pokemon-official-ja-xy7-b`、`pokemon-official-ja-xy7-b-001`。
- 系列名取官方卡片搜尋 `pg=<商品 ID>` 的 `searchCondition`（去掉「ポケモンカードゲームXY／XY BREAK」品牌前綴），發售日取官方商品清單中唯一同名商品的日期，否則留空（ADR 0012 補充的規則）。
- 範圍：30 個專屬單一商品的標記（擴充包 15、牌組與特殊包 15）。不匯入 `XY`（THE BEST OF XY 與其他商品共用的再錄標記，387 張跨多個商品）、`BW`、`SM-XY`（再錄標記），以及已由封存匯入的 CP1、CP2。
- 封存的 `XY1a`、`XY2`…等系列檔代碼與官方標記不同，兩者不視為同一系列；日後若封存補上卡名，需先比對官方標記再決定，不得重複匯入同一商品。

## Consequences

- 日版 XY 世代的系列代碼與一般通稱（XY7）不同，搜尋時以系列名與 `XY7-B-001` 這類別名為主。
- 稀有度依 ADR 0007；中文名依 ADR 0011／0013。
