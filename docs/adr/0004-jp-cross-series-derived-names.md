# 同一世代內唯一對應時，允許跨系列的同名推導名稱

ADR 0003 只允許在同一 Series 內同名推導中文名，因此沒有台版的系列（SVLN、SVLS、SVK）與各系列的少數再錄卡仍缺中文名。這些多半是在其他朱紫系列已有台版官方名稱的卡（如ハイパーボール、博士の研究、ナンジャモ）。

決定：在同一 Series 推不出時，可改用 Source archive 中**朱紫世代所有系列**（`data-asia/SV`）建立「日文名 → 繁中名」對照；只有當該日文名在整個世代只對應**唯一一個**繁中名，且資料庫中確有一張台版卡帶著完全相同的中文名時，才採用為 Derived name，並在計畫中引用那張台版卡（`nameSource`）。資料庫函式逐張驗證被引用的台版卡存在、屬台版且中文名完全一致；日文名的對應由計畫的 evidenceHash 綁定的封存證據證明。

排除 SV-P（促銷卡）：2026-10-01 全世代比對發現 SV-P 的日版與台版編號不對齊，同一編號的 `zh-tw` 常屬另一張卡（如 `ウインディ → 呆火鱷`），55 筆不一致全集中於此；其餘系列的不一致只有零寬字元或空白差異，以「必須唯一」規則自然隔離。

## Consequences

- 新增名稱依據 `derived-cross-series`，介面同樣標示「同名推導」；它只是名稱，不是身分證據，不連結作品層。
- 一個日文名若因空白或零寬字元出現兩種寫法即視為不唯一而不推導（例如基本能量、ワザマシン デヴォリューション），寧可留空。
- 已建立的 649 個同系列連結經同一比對覆核，未發現錯位；被標記的 5 筆皆為正確名稱，僅因 SV-P 的錯誤資料讓「多數」失準。
- 若日後 TCGdex 修正 SV-P，需重新比對後才可納入。
