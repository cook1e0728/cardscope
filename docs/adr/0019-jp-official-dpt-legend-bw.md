# 日版 DPt、LEGEND、BW 世代以日本官方卡片搜尋匯入

掃描官方卡片搜尋的商品 ID 1–379（`official-product-ids-dptbw-20261004.json`）發現官方也收錄 DP、DPt、LEGEND、BW 世代，系列標記同 XY 世代帶後綴（`DPt1-B`、`L1-Bhg`、`BW1-Bb`）。決定（2026-10-04，grill-with-docs 形式提出建議並照建議執行；AGENTS 規定的 Sol 裁決在此環境不可用）：

- 範圍：詳細頁有卡號的 DPt、LEGEND、BW 世代代碼，依 ADR 0012／0018 匯入（83 個代碼）。DP 世代（DP1–DP5、DP、DPs-*）詳細頁沒有卡號，依「官方卡號為身分」不匯入；PW、DPP、WCP 同樣排除。
- 稀有度：XY 以前的官方圖示名稱可能不代表今天的代碼（例如早期 `ic_rare_s` 可能是「★」而非色違 S），只對映 C、U、R、RR、SR、UR，其他圖示維持未知（計畫產生器 `--rarity-codes`）。
- 系列名：同 ADR 0012 補充規則，取只含該代碼的具名商品（去品牌前綴、排除「（…全てのカード）」彙總項）；同一牌組有多種寫法的商品列（如「エントリーパック(ギラティナデッキ)」與「エントリーパック：ギラティナデッキ」）取商品 ID 最小者的完整名稱，避免不同牌組被併成同名。發售日取官方商品清單中唯一同名商品（83 個中 54 個有日期）。
- 中文名依 ADR 0013 推導；台灣官方未收錄這些世代。

## Consequences

- 日版收錄延伸到 2008 年以後的商品；DP 世代需另立「無卡號」的身分規則才能匯入。
- 早期世代的稀有度多為未知，Printing 為 `incomplete`。
