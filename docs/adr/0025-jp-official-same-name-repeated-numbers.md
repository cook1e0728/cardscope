# 日版官方清單中同卡號、同名的多個詳細頁視為同一張卡

ADR 0012 匯入日版官方系列時，同一卡號出現在多個詳細頁就整號隔離。盤點（2026-10-05）：各系列匯入報告共有 210 頁因此隔離，對應 90 個卡號。其中 80 個卡號的所有頁面日文名相同（例如 SVI 002 ニャオハex 兩頁、WAK 041 きずぐすり 兩頁、SML 041 スーパーボール 三頁），是同一張卡收錄在同系列的不同牌組；另外 10 個卡號全在 MG，同號不同名（モンジャラ／ミュウツー），因為 MG 兩副牌組各自從 001 編號。台版在 ADR 0015 已採用「每號一張、同號各版本須同名」。

決定（2026-10-05，使用者授權照建議執行）：

- 同系列、同卡號、各詳細頁日文名完全相同時，視為一張卡：Provider ID 取最小的官方詳細頁 ID（可靠的官方 Provider ID），全部頁 ID 記在 metadata `officialCardIds`。ID 規則與 ADR 0012 相同（`pokemon-official-ja-<系列>-<卡號>`）。
- 系列把關：系列中只要有一個卡號同號不同名，表示卡號在該系列不能辨識卡片，整系列不套用（MG 因此排除，連同其中同號同名的 6 號）。
- 稀有度：各頁的官方圖示對映須一致才採用，否則留空（ADR 0007）；XY 以前的系列只保留 ADR 0019 的代碼。
- 寫入：補進既有的日版官方系列，只新增不修改；`private.supplement_pokemon_jp_official_series`（每系列一批 ≤100、gated dry-run、digest 重播、追加式稽核 `private.catalog_jp_official_supplement_audit`），並檢查所有列出的詳細頁 ID 都未被既有列使用。
- 中文名與日台連結沿用既有流程（ADR 0011／0013、ADR 0024），不另訂規則。

## Consequences

- 2026-10-05：25 個系列補入 74 張（稀有度皆未知，官方頁無圖示），重播零異動；MG 排除。之後依既有規則：ADR 0011 為 SVI／SVAL／SVAM／SVAW／SVC／SVEL／SVEM 的 32 張取得台灣官方中文名與「無標記」，ADR 0024 連結這 32 張到台版；ADR 0013 推導 29 張中文名；13 張仍無中文名（ポケモンキャッチャー 一對多、10 張資料庫無官方名）。
- 牌組類系列補齊重複收錄的訓練家卡與 ex 卡，系列張數更接近官方清單。
- 沒有卡號的頁面（多為基本能量、特典的無編號卡）仍然隔離；MG 需要以商品（牌組）區分身分，另案處理（同號不同名的處理見 ADR 0032）。
- 2026-10-10：劍盾的 SI（スタートデッキ100）補 126 張（分兩份計畫，補卡函式改為同系列可多份）、SH（ファミリーポケモンカードゲーム）補 10 張，重播零異動。查證發現同號同名的多頁在實體上並不完全相同：SH 040 きずぐすり 兩頁右下的牌組標記不同（火球鼠剪影／皮卡丘），SI 101 ブイゼル 兩頁的卡片背景紋路不同。本 ADR 仍把它們視為一張卡（收藏者可能會區分），所有版本的官方 ID 記在 `officialCardIds`，主圖只用最小 ID 那一頁。
