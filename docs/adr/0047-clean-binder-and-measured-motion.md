# 視覺質感：乾淨卡冊（版面）＋適度動態

**狀態：已採用（2026-10-21，使用者以 https://prompt-motion.com/ 為參考，看過預覽分支的改前／改後對照圖後選「A＋B 都採用」）。延續 ADR 0044 Q4（視覺類先預覽）。**

使用者覺得網站視覺質感不夠。grill 四題照建議：兩層都要但先做版面、保留卡冊主題、動態適度放寬、預覽分支做兩個方向比較。

決定：

- **A 乾淨卡冊（`look-clean.css`）**：保留紙色底與 IP 主色；統一間距尺度（4–64）、字級三到四級、Space Grotesk 等寬數字；拿掉大部分盒中盒與框線，改留白＋淡分隔線，只留一種淡陰影；遊戲分頁籤、版本、篩選改膠囊、選中加 ✓ 與外框；槍鐵灰卡套只包卡圖、縮到 3px；詳細頁改「小標籤、大數值」分隔列表與底線式分頁；篩選列不再固定頂端；停掉首頁與分頁籤的持續反光。對比 AA 全過，手機 390 寬無橫向捲動。
- **B 適度動態（`look-motion.css`、`look-motion.js`）**：卡片進入視窗時依序淡入（260ms、上浮 8px、`cubic-bezier(.23,1,.32,1)`、每張錯開 30ms 最多 12 張，已出現的卡不重播）；只在 `(hover:hover) and (pointer:fine)` 有懸停傾斜（X ±4°、Y ±5°，沿用詳細頁 `tilt-card` 的算法與變數）與卡套框上的淡光澤（不在卡圖上）；`prefers-reduced-motion` 時全部不啟用；左下角「暫停動態」開關（`role="switch"`、44px、存 localStorage `cardscope-motion-paused`）。
- **SAMPLE 浮水印**：不採用 A 預覽中的「右下角小標」，維持使用者先前選的「中央、調淡」（依序執行 113）。
- **上線方式**：`<html class="look-clean look-motion">`，兩檔直接載入；`?look=` 預覽開關移除。

## Consequences

- 主方案第 5 節的動畫限制（120–180ms、≤4px）依本 ADR 放寬，已在主方案註明。
- 左下角「暫停動態」開關在桌面會蓋住一小塊內容；桌面第一屏通常看不到淡入（卡片格在系列橫幅下方）。
- 尚未做的版面項目（需要改其他檔）：區域與系列分頁籤旁附數量（`series-band.js` 要輸出數量）、詳細頁「原始頁面」連結觸控區只有 24px、手機篩選攤成膠囊列。
