# 日版卡以「同系列代碼、同官方卡號」連結台版卡，並以整系列對齊把關

ADR 0003 只在 Source archive 的 Provider ID 相同時連結日台；ADR 0015 只連結中文名依 ADR 0011 取得、且台版卡來自台灣官方匯入的日版卡。盤點（2026-10-04）發現 36 個系列約 2,500 張日版卡沒有連結，但資料庫中有同系列代碼、同卡號的台版卡：日版卡多半是日本官方匯入（沒有 Source archive 的 Provider ID），或台版卡是 Source archive（ADR 0015 的函式不收），或日版中文名是推導（ADR 0004／0013）。詞彙表 Canonical card 已規定官方編號可以證明身分。

決定（2026-10-04，使用者授權照建議執行）：

- 身分證據是**同系列代碼＋同官方卡號**；中文名須一致（ADR 0010 名稱規則：去 Source name markup、NFKC、零寬字元，以及官方標題省略卡面括號註記），只作一致性檢查。
- 整系列把關（比照 ADR 0011）：同系列中，日版有中文名的每一組同號配對都必須一致，任一不符整系列不連結；已連結的日版卡不得連到不同卡號的台版卡。卡號錯位的系列（SV-P、SVK、MBD、MBG、SVHK、SVHM、SVOM、SVOD）因此全部排除。
- 推導名稱可作一致性檢查（ADR 0011 已把推導名稱列為對齊證據）；日版沒有中文名的卡不連結。
- 已連結到其他作品層的日版卡（例如 ADR 0016 的範例卡）、同號有多張的卡、已被共用的台版作品層，一律跳過。
- 寫入：`private.link_pokemon_jp_tw_same_number`（規則 `adr-0024`，每次 ≤100 列，資料庫端逐列與逐系列重查，dry-run、重播零異動、沿用追加式稽核 `private.catalog_jp_tw_link_audit`）。只改日版卡的 `canonical_id` 與連結 metadata，不改名稱；原本的日版 Canonical card 保留以便還原（同 ADR 0003）。

## Consequences

- 日版詳細頁可並列同號台版 Printing；作品層同時有日文與中文名稱。
- 之後新匯入的系列可用同一流程連結；錯位系列需要不同的身分證據，維持不連結。
