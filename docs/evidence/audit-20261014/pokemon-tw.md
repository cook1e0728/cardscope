# 寶可夢台版（繁體中文）目錄完整性稽核（2026-10-14）

唯讀稽核：台灣官方卡片搜尋（asia.pokemon-card.com/tw）對照資料庫台版 146 個系列、12,669 張卡。完整數據見 `pokemon-tw.json`。

## 結論

- **10 月以後沒有新系列。** 官方系列代碼仍是 134 個，與 2026-10-03 的清單完全相同；最新的是 MF、M6a（2026-09-16）。131 個系列的官方卡片 ID 與 10-02 快取逐一相同（沒有新增或移除）。
- **官方有、資料庫沒有的系列：3 個**，都是特典卡：M-P（208 張）、S-P（151 張）、SM-P（1 張）。HANDOFF 26 本來就列為「尚未處理」。
- **最大的缺口是既有系列缺卡：21 個系列共缺 582 個卡號**（扣掉 SV-P 是 449）。集中在 TCGdex 來源的朱紫早期系列：只收到印刷總數為止，官方還有祕密稀有卡（AR／SR／SAR／UR）在總數之後。ADR 0023 只補了 SV9、SV10，其餘還沒補。
- **欄位（卡號、中文名、稀有度）幾乎完全一致。** 最近 7 個系列（MF、M6a、M6、MTL、MTS、MTH、MTK，共 399 張）用今天的詳細頁與稀有度篩選核對：卡號 0 差異、中文名 0 差異、稀有度只有 M6a 134、135 兩張差異。其餘系列用 10-02 快取核對（12,182 張）：卡號、中文名 0 差異，稀有度只有 AC2a／AC2b 的 27 張。
- 資料庫 15 個 `CS*` 系列（CS1.5、CS1a…CSA）是空殼，官方站沒有對應系列。系列名稱 131 個全部與官方名稱相符。

## 張數不同的系列與原因

**A. 缺祕密稀有卡（卡號在印刷總數之上）— 資料庫停在印刷總數**：SV1S／SV1V 各缺 30（079–108）、SV1a 30（074–103）、SV2D／SV2P 各缺 28（072–099）、SV2a 3（208–210）、SV3 3（139–141）、SV3a 3（090–092）、SV4K／SV4M 各缺 29（067–095）、SV5a 30（067–096）、SV5M 3（098–100）、SV6 3（131–133）、SV6a 30（065–094）、SV7 3（133–135）、SV7a 30（065–094）、SV8 32（107–138）。合計 344 張。這些系列來源是 TCGdex，沒有總數以上的卡號；官方清單與稀有度已在快取中，做法與 ADR 0023（SV9／SV10 補號）相同。

**B. 系列中間有洞（TCGdex 本身不完整）**：SV5K 缺 54（022–073 中大部分，另有 098–100）、SV4a 缺 46（127–167 共 40 張，另有 355–360 共 6 張）。

**C. SV-P 缺 133 個一般 3 位數卡號**：資料庫 94 列（TCGdex），官方有 214 個有卡號的卡（001–265 之間）。另外資料庫的「56」與官方「056」疑似同一張的補零差異，未處理。

**D. MC 缺 5**（273、274、278、279、287）：匯入時以 `VERSION_NAME_CONFLICT` 隔離，原因是同號兩個官方版本的名稱只差 `<奇樹的>`、`<莉莉艾的>` 這種標記，而名稱比對函式 `twNameKey` 其實會把標記去掉。可以回補（見 `MC-import-report-20261003.json`）。

**E. 已知排除項（不算問題）**：基本能量沒有卡號（資料庫用 DAR／FIG／FIR／GRA／LIG／MET／PSY／WAT 代碼，19 個系列）；V-UNION 分片（S8a 025、S8b 056、SP5 001／005／009）；SV-P 特殊編號（no0–no3）；M6a 的 LEGEND 兩片卡（官方卡號 `151/103,152`，資料庫沒有 151、152，性質同 V-UNION）。

沒有任何「資料庫有、官方沒有」的非已知卡號，也沒有找到無法歸類的差異。

## 欄位差異

1. **M6a 134 超夢ex、135 夢幻ex**：官方稀有度 `FUR`（篩選值 22），資料庫沒有這個代碼，稀有度為空、Printing 為 incomplete。
2. **AC2a 14 張、AC2b 13 張（名稱後綴 ◇）**：官方稀有度 `PR`（篩選值 6），資料庫沒有 PR 代碼，稀有度為空。
3. 其餘台版稀有度為空的 88 張是已知項目（基本能量、V-UNION、SV-P 特殊編號）。台版空值合計 117 = 88 + 27 + 2。

## 建議的下一步（依使用者價值排序）

1. **補 A 類 344 張祕密稀有卡**（SV1–SV8 的 AR／SR／SAR／UR）：這是玩家最常搜尋的卡，且做法現成（ADR 0023 的補號流程；官方稀有度已在 `official-rarity-20261002.json`）。先確認各系列已有卡號與官方同名。
2. **補 B 類 SV5K、SV4a 的洞**（100 張）：同一流程，但這兩個系列洞在中間，要先確認補號不會撞到既有卡。
3. **匯入特典 SV-P 缺的 133 張與 M-P、S-P、SM-P**：特典卡熱門，但卡號格式特殊（`001/SV-P`、系列標記 `PROMO.MARK`），需要先讀詳細頁並新增 ADR。
4. **新增稀有度代碼 FUR、PR**（需 ADR 與資料庫稀有度表）：共 29 張，補完後台版空值只剩已知項目。
5. **回補 MC 的 5 張**：小範圍，可併入第 1 項的計畫。
6. 清掉 15 個 `CS*` 空殼系列（無卡、官方也沒有）：低優先，純整理。
