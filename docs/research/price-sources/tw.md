## 調查方式與限制

- 只讀條款、robots.txt，最多 1–2 個樣本頁；不登入、不繞過防護、不大量請求、不蒐集個資。
- 以誠實的 User-Agent 對各站 `robots.txt` 與條款頁各發一次請求；JS 渲染的條款頁以瀏覽器窗格一般瀏覽讀取。
- 遇到 Cloudflare 驗證、403 或必須登入的頁面一律停手，記「無法確認」，不嘗試繞過。
- 條文引用皆 15 字以內，其餘為自己的摘要。條款可能隨時修訂，採用任何來源前須重新核對全文。
- 所有「風險等級」是對 CardScope 現有原則（不繞過反爬、不複製競品、來源授權不明採保守策略）的評估，不是法律意見。

## 各來源說明

### 1. 卡拍拍

1. 網址：App 官網 `kapaipai.tw`，主站應用在 `trade.kapaipai.tw`（SPA）。價格性質為賣家掛牌與競標（listing）；站內另有「行情」標籤與「登入查看價格走勢」，走勢的資料定義與來源無法確認。幣別站內未明確標示。App Store 描述為「遊戲卡牌交易市場」，不是獨立行情資料庫。
2. 條款（`trade.kapaipai.tw` 內嵌「卡拍拍用戶服務條款」，頁面未標示日期）：
   - 3.1：授權只是有限且可撤回；禁止複製、散布、再發行、公開展示本站內容；未經書面同意不得用機器人、蜘蛛或其他自動／手動程序「監視或複製」內容（搜尋引擎標準索引視為同意）。
   - 6.2(dd)：禁止以程式、腳本、爬蟲、擷取工具對平台內容做系統性存取、擷取、複製、收集、索引或儲存，並明列禁止模擬使用者大量下載、繞過頻率限制或驗證碼、對其 API 未經授權呼叫或逆向、以代理／VPN 隱匿 IP。
   - 另有條款禁止在其平台蒐集其他使用者的個人資料；站內含買賣雙方個資。
3. robots.txt：`/robots.txt` 回傳 SPA 首頁 HTML（等同沒有 robots 規則），所以不能把「沒有 Disallow」解讀為允許。
4. 官方 API／合作：未見公開 API 或聯盟；條款反而禁止未經授權呼叫其 API。
5. 風險：**高**。條款明文禁止，價格走勢需登入，且主方案已定「不複製卡拍拍」。技術難度高。
   - 結論：只作為理解玩家需求的對照，不接。

### 2. 露天拍賣

1. 網址 `https://www.ruten.com.tw/`。價格為賣家掛牌（直購／競標，listing）；商品頁的「歷史」頁被 robots 擋，成交紀錄能否取得無法確認。幣別 TWD。商品標題為賣家自由填寫，無法穩定對應系列代碼＋卡號。
2. 條款：「會員合約」`https://www.ruten.com.tw/help/member/4401/`（頁面未標更新日）。
   - 第三條(13)：會員不因加入而取得任何授權，非經露天書面同意，不得使用、重製或散布平台上任何著作、資料、商標、標識。
   - 第三條(3)a：會員不得以「網路爬蟲」大量爬取他人圖文並刊登於露天（方向是搬運內容上架，並非直接談抓取露天資料，但顯示其對爬蟲的態度）。
   - 第十二條：賣家上傳內容授權的對象是露天，並非第三方。
   - 第十三條：個人資料保護；平台資料含買賣家個資。
   - 全篇未見「禁止自動化存取價格」的明確文字，但第三條(13)的書面同意要求已足以構成風險。
3. robots.txt（`/robots.txt`，345 bytes，對所有 UA）：擋 `/item/show?`、`/item/qa?`、`/item/qa_full?`、`/item/history?`、`/item/history_full.php?`、`/item/violate.htm?`、`/message/`、`/find/more/`、`/find/store-ad/`、`/system/chgview.php?`、`/search/s000.php`、`/search/ulist00.php`、`/cdn-cgi/`。商品頁與搜尋頁都在擋的範圍。附註：某些抓取工具對同一網址回 404，只有一般 HTTP 請求能取得，顯示站方有 UA 判斷。
4. 官方 API：有「OPEN API 申請流程」`https://www.ruten.com.tw/help/seller/11335/`，放在賣家中心，需填表申請，收 API Key／Secret Key／Salt Key，以 HMAC-SHA256 簽章。規格書（商品、訂單）為 PDF，我未能讀取內容，所以能否查詢他人賣場商品或公開行情「無法確認」；依其位置與內容推測是賣家管理自家商品／訂單用。聯盟：`pub.ruten.com.tw/3c_alliance/` 轉到活動頁，內容為 JS 渲染，是否為聯盟行銷無法確認。
5. 風險：**高**。robots 擋商品頁與搜尋頁，條款要求書面同意，API 為賣家用。技術難度高。
   - 可行路徑只有「向露天書面詢問資料授權」，不在本次範圍。

### 3. 蝦皮購物

1. 網址 `https://shopee.tw/`。價格為掛牌（listing），TWD；全品類，標題自由填寫，無法對應系列代碼＋卡號。
2. 條款：「蝦皮服務條款」`https://help.shopee.tw/portal/article/77267`。
   - 3.1：未事先獲書面同意，不得用機器人程式、蜘蛛程式或任何自動裝置或手動程序監視或複製內容；也禁止鏡像、框架、再發行（搜尋引擎標準索引除外）。
   - 6.2(k)：禁止以非官方軟硬體（含模擬器、機器人）使用平台。
   - 條款內含個人資料保護與買賣家個資相關條文。
3. robots.txt：兩組規則。`Googlebot／Bingbot` 群組 Crawl-delay 0.1，並擋較多路徑；`*` 群組 Crawl-delay 1，擋 `/cart/`、`/checkout/`、`/user/`、`/me/`、`/order/`、`/daily_discover/`、`/top_products`、`/search*searchPrefill` 等，另提供商品 Sitemap。robots 允許不等於條款授權。
4. 官方 API／聯盟：Open Platform `https://open.shopee.com/` 首頁以「Add Item、Get Order Detail、Ship Order」為核心，面向賣家／ERP／服務商，不是行情查詢。蝦皮另有分潤聯盟（面向創作者導購），台灣是否有可取得商品資料的聯盟 API，我查不到可靠來源，無法確認。
5. 風險：**高**。條款明確、站方有前端防護（以非瀏覽器方式讀取條款頁即只拿到空殼）。技術難度高。

### 4. Yahoo 奇摩拍賣

1. 網址 `https://tw.bid.yahoo.com/`。價格為掛牌（直購／競標，listing），TWD。樣本頁（一個收納盒商品）為 SPA，標題自由填寫，無法對應系列代碼＋卡號。Yahoo 自家文章 `https://tw.bid.yahoo.com/act/article/card-collecting-guide.html` 提到玩家用拍賣站查成交價，但頁面沒有說明已結標紀錄的開放方式，所以 S 無法確認。
2. 條款：「Yahoo購物」服務條款（涵蓋拍賣）`https://tw.buy.yahoo.com/ec/atos`，最近更新 2026/07。
   - 第三條「會員規範」：未獲明確事前允許，不得以機器人、爬蟲、網頁抓取器、資料探勘等自動化方式存取或蒐集服務資料。
   - 同條：不得利用服務資料建立資料庫、彙整來源或資料摘要，從事競爭或構成實質性服務替代（對聚合型產品是直接衝突）。
   - 第六條「關於Yahoo拍賣」：賣家上載商品資料時授權 Yahoo 重製、散布；沒有授權第三方。
   - 另有全站「Yahoo 服務條款」`https://legal.yahoo.com/e2/zh-hant/yahoo/terms/otos/index.html` 有相同方向的自動化存取禁令（頁面無條號，條號無法確認）。
   - 涉及個人資料：會員、賣家資料。
3. robots.txt：`User-agent: *`，`Allow: /sitemap/`；擋 `/partner/`、`/myauc/`、`/checkout/`、`/compareshopping`，有 Sitemap。限制很少，但與條款相衝。
4. 官方 API／合作：搜尋未找到對外開放的拍賣 API（賣家工具或第三方串接）；不得視為不存在，只能說無法確認。
5. 風險：**高**（條款明確，且「建立競爭性資料庫」一款直接點到聚合服務）。技術難度中高。

### 5. PChome 商店街

4. 官方 API／合作：無。
5. 風險：不適用（沒有可用資料）。附註：PChome 24h 購物（`shopping.pchome.com.tw`）是另一個站，robots 擋 `/items/*`、`/vip/*` 等；搜尋結果顯示其寶可夢官方店多為盒裝，不是單卡行情，本次未深入。

### 6. 台灣主要卡牌店網路商店

台灣找到的「大店」資料公開度都不高；本節讀了三個台灣來源（決鬥城市、TCGSTORE、小店 Cosmoxmusic），另有兩個香港店放在第 7 節。沒有任何一家能直接證實為「成交價」。

#### 6a. 決鬥城市卡牌專賣店

1. 網址 `https://www.battlecity.com.tw/`（台北車站地下街；營業人「盛嘉企業社」）。價格為店售標價（listing），推測 TWD。分類含遊戲王單卡區、航海王、寶可夢等。樣本品項頁價格因動態載入未能確認，系列代碼＋卡號能否對應無法確認。
2. 條款：「會員條款」`https://www.battlecity.com.tw/info/Terms`。第八條：不得破壞或干擾網站各項資料與功能，嚴禁入侵或破壞系統；全文未見自動擷取、轉載、商業使用的明確條文。涉及會員個資。
3. robots.txt：404（回傳「找不到網頁」），無規則。
4. API／合作：無（頁面有「合作提案」連結，可作為洽談入口）。
5. 風險：**中**。條款沒禁但也沒授權，且是單一小企業；建議書面詢問。技術難度中（動態載入）。

#### 6b. TCGSTORE 卡牌專屬交易平台

2. 條款：首頁頁尾「使用者服務及隱私條款」為 PDF（`/document/使用者服務條款.pdf`，檔案屬性建立日 2022-07-14）。我嘗試以工具抽出文字，中文字體無法解析，所以條文內容「無法確認」。涉及買賣家個資與請款資料。
3. robots.txt：`User-agent: *`、`Allow: /`，有 `Sitemap`。（開放，但不代表條款允許。）
4. API／合作：無。
5. 風險：**中高**（條款未讀，且是賣家掛牌資料）。技術難度中（Next.js）。

### 7. 香港華語來源（補充）

#### 7a. 皇巢卡店 Beehive

1. 網址 `https://beehivetcg.com/`（Shopify，香港觀塘）。店售標價（listing），HKD，例如 `AGOV-JP030 … HR` 標 HK$40.00，並顯示庫存。另有獨立買取網站 `https://beehivetcgbuylist.com/`（WooCommerce），列「Pokemon 日版 回收表」等，含系列碼＋卡號（如 `SV8 132/106`）、買取價與可買取數量；買取價顯示為 `$4,000.00`，未標幣別（推測 HKD，無法確認）。買取站也列出繁中系列（如 `SV8F`、`M3F`）。性質：店售＝listing；買取＝buyback。
2. 條款：商店條款 `https://beehivetcg.com/policies/terms-of-service`。2.1：授權僅限個人非商業用途；2.2：不得複製、修改、分發、出售或租借其服務。買取站頁尾的「服務條款」連結（`/pages/服務條款`）在兩個網域都是 404，所以買取站條款「無法確認」。涉及客戶個資（僅在購買流程）。
3. robots.txt：Shopify 標準規則，允許大多數頁面；擋 `/cart/`、`/checkout`、`/account` 與 `/collections/*sort_by*` 等；註解寫明結帳需人為核准，AJAX 介面請用 UCP/MCP。買取站：只擋 WooCommerce 內部路徑與 `add-to-cart`，有 Sitemap。
4. 官方 API／合作：店家宣告 UCP（Universal Commerce Protocol）與 MCP 端點，用途是讓購物 agent 代使用者購買，不是行情資料授權；不應視為可取用。
5. 風險：**中**。技術上最乾淨、資料最接近「繁中玩家」需要的買取價，但條款限個人非商業，需要店家書面同意；而且是港幣、香港買取價，不能當台灣行情。技術難度低。

#### 7b. BraveSoul 卡牌（HK）

1. 網址 `https://www.bravesoulcard.com/`（Shopline，香港鑽石山）。店售（listing），預設 HKD，可切換 TWD 顯示（換算性質，不是台灣價格）。商品分類含 Pokemon TCG 繁中／日文散卡、航海王散卡；另有「TCG卡牌回收」頁 `/pages/sellcard`（內容為前端渲染，買取價細節無法確認，只知僅適用寶可夢）。
2. 條款：`/about/terms`，內容 JS 渲染，未能讀取，無法確認。
3. robots.txt：Shopline 範本，對 `MJ12bot`、`HubSpot` 全擋；`*` 群組 Crawl-delay 5，擋 `/closed`、`/preview/`、`/users/`、`/orders`、`/api/` 等，並附 Sitemap。
4. API／合作：無。
5. 風險：**中**（條款未讀）。技術難度低。

#### 7c. Carousell 香港

1. 網址 `https://hk.carousell.com/`。個人掛牌（listing），HKD，全品類，標題自由填寫。
2. 條款：「[Hong Kong] Terms of Service」`https://support.carousell.com/hc/en-us/articles/33729467581849--Hong-Kong-Terms-of-Service`。第 2 條「使用服務」的禁止清單明列：不得用 scraper、robot、bot、spider、crawler 或其他自動化裝置／方式存取、取得、複製或監視服務或其資料；不得蒐集其他使用者資訊。另一款提到 API 須遵守專屬條款。涉及使用者個資。
3. robots.txt：`User-agent: *` 擋 `/search/`、`/inbox/`、`/myprofile/`、`/*?`（所有帶參數網址）等；另對 `AdsBot`、`Mediapartners-Google` 開放。
4. API／合作：未見對一般開發者開放的資料 API（條款只提到「提供給你的 API」須遵守專屬條款）。Zendesk 說明站對非瀏覽器請求回 Cloudflare 驗證（HTTP 403），我沒有繞過，條款是用瀏覽器窗格一般瀏覽讀取。
5. 風險：**高**（條款明確、robots 擋搜尋與參數頁、站方有 Cloudflare）。技術難度高。

### 8. PTT／Dcard 交易板（只評估，不建議抓個資）

#### 8a. PTT

1. 網址 `https://www.ptt.cc/`。貼文為使用者自由文字，價格、品相、聯絡方式皆非結構化，性質（掛牌／買取／成交）需逐篇人工判斷，不能機器歸類。我找不到有明確卡牌交易板的證據（只確認 `PokeMon` 看板存在，未讀內容）。
2. 條款：找不到集中式服務條款頁，板規各板自訂；無法確認。涉及大量個人資料（帳號 ID、聯絡方式、可能的真名／電話）。
3. robots.txt：404，沒有規則。
4. API／合作：無。
5. 風險：**高**（個資＋非結構化＋無明確授權）。技術難度高。不建議。

#### 8b. Dcard

1. 網址 `https://www.dcard.tw/`。貼文為使用者自由文字，性質同上，我沒有找到穩定的卡牌交易板。
2. 條款：「Dcard 用戶使用協議」`https://www.dcard.tw/terms`。
   - 「用戶行為限制」：禁止以自動化「登入及操作」蒐集其他用戶的內容；禁止未經書面同意利用服務從事商業行為或做商業用途；禁止違反個資法蒐集他人資料；禁止造成系統過載。
   - 「用戶內容授權」：用戶內容授權給 Dcard，並非第三方。
3. robots.txt：只擋 `/emails/activate`，有 Sitemap。對非瀏覽器請求，條款頁回 403（`curl` 取得），我沒有繞過，條款是用瀏覽器窗格閱讀。
4. API／合作：無公開 API。
5. 風險：**高**。技術難度高。不建議。

## 未能確認的點

- 卡拍拍：價格走勢的資料性質與幣別；系列代碼是否在站內顯示；條款日期。
- 露天：OPEN API 規格書內容（能否查他人商品）；是否有成交紀錄開放；聯盟行銷頁；會員合約日期。
- 蝦皮：台灣是否有可取得商品資料的聯盟 API。
- Yahoo 奇摩拍賣：已結標紀錄是否公開、能否取得；全站 Yahoo 服務條款的條號；是否有對外 API。
- PChome 商店街：「服務約定條款」全文（已停止交易，未追讀）。
- 決鬥城市：品項頁價格與卡號格式（動態載入）。
- TCGSTORE：條款 PDF 全文（工具無法抽出中文）。
- BraveSoul：服務條款與買取表內容（JS 渲染）。
- 皇巢買取站：服務條款（連結 404）與幣別。
- PTT：是否有集中條款、是否有可用的卡牌交易板。
- Carousell／Dcard／蝦皮：靠一般瀏覽讀取條款；非瀏覽器請求被 Cloudflare 或前端防護擋下，未繞過。

## 建議

1. **沒有「風險可接受、可直接用程式讀取」的台灣來源。** 四大平台（卡拍拍、露天、蝦皮、Yahoo 奇摩拍賣）與 Carousell、Dcard 都有明文或實質的自動化存取限制，其中卡拍拍、蝦皮、Yahoo、Carousell、Dcard 是明文禁止；露天則是 robots 擋商品頁與搜尋頁，再加書面同意條款。PTT 則是個資與非結構化問題。這些來源都與主方案原則（不繞過反爬、不複製競品、授權不明採保守）衝突。
2. **PChome 商店街已停止平台交易，從清單移除。**
3. **價格可靠度最高、技術上最乾淨的是店家端，且需要先取得書面同意**，依序：
   - 皇巢 Beehive（香港）：有買取（buyback）資料，含繁中系列與系列碼＋卡號，結構最好；但條款限個人非商業、幣別 HKD，只能作為「香港買取價」標示，不可當台灣行情。
   - 決鬥城市（台北）與 Cosmoxmusic：台灣店售標價，結構與授權待確認；Cosmoxmusic 的標題格式最接近 CardScope 身分對應需求，但規模小。
   - TCGSTORE：先讀懂條款 PDF（需向站方索取文字版）再評估。
4. **短期做法**（供主線決策，不屬於本研究的執行項）：維持 CardScope 現行單一來源買取（遊々亭）與既有「單一來源買取漲幅」措辭；台灣新台幣行情在取得至少一家店家書面同意前，一律顯示「尚未取得可靠資料」，不用任何平台掛牌價推算行情，也不把 listing 標成成交價。
5. **若要拓展台灣來源，建議的順序**：先寄信詢問皇巢與決鬥城市是否同意以「標示來源、連回原頁、只顯示價格與時間」的方式使用資料（書面留存）；若同意，再依 ADR 流程新增資料來源。這需要使用者批准新資料來源，我沒有啟用任何來源，也沒有寫入資料庫。
6. **PTT／Dcard**：只用於理解玩家用語與痛點，不抓取、不蒐集任何個資。
