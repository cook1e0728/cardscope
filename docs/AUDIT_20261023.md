# CardScope 全站審查（2026-10-23）

決策見 ADR 0052。審查員只讀實測正式站（Edge＋Playwright、公開 API、程式碼審視），主管核對證據後修正。狀態：✅ 已修上線、🟡 部分處理、⏸ 待使用者決定、➖ 不處理（附理由）。

## 伺服器性能與穩定、安全

| 嚴重度 | 發現 | 狀態 |
|---|---|---|
| 高 | 一個壞的 `%` 編碼網址（`/api/cards/%E0%A4%A`）讓整個程序崩潰重啟，任何人都能觸發 | ✅ 例外只讓單一請求失敗，回 400 |
| 中 | 靜態檔沒有白名單：`/server.mjs`、`/package.json`、`/providers/*`、`/docs/*`、`/CLAUDE.md`、`/.codex/config.toml` 皆可讀 | ✅ 改白名單，其餘 404（`.env.local` 原本就不在 repo） |
| 中 | 沒有安全標頭 | ✅ nosniff、Referrer-Policy、X-Frame-Options、HSTS（CSP 尚未加，首頁有 inline script） |
| 中 | 首頁抓 3 次覆蓋率報告（每次解壓約 3 MB） | ✅ 共用一次 |
| 中 | 目錄類 API 全部 `no-store` | ✅ 1 分鐘瀏覽器快取＋5 分鐘舊值可用 |
| 中 | 手機首頁 CLS 0.08–0.24 | 🟡 版面收緊、骨架畫面；未逐一量測 |
| 低 | 搜尋字數、`/api/cards` offset 無上限 | ✅ 100 字、200,000 |
| 低 | `keep-warm.yml` 實際間隔 2–7 小時 | ➖ 真正保持喚醒的是 UptimeRobot（每 5 分鐘），workflow 留作備援 |
| 低 | 字型 2.5 MB、CSS 5 支阻塞渲染 | ⏸ 字型子集化另案 |

實測（暖機 p50）：搜尋 240–350 ms、`/api/cards` 238 ms、首頁 LCP 0.8–1.2 s。分享連結開卡 6.0 s → 3.0 s。
