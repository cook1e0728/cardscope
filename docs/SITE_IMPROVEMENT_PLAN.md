## 2. 目標與不做的事

**目標（做完的樣子）：**
1. 安全：第 1 節問題 1–5 全部關掉，並有測試擋住再犯。
2. 功能：第一次來的人在手機上 3 次點擊內找到一張卡，過程中沒有誤導的畫面（問題 6–11）。
3. 版面：照 REDESIGN_PLAN 的 B′ 完成，全站一種頂欄、一套按鈕、三層底色。
4. 速度：暖機後搜尋 P95 < 800 ms、LCP < 2.5 s、CLS < 0.1（PRODUCT_PLAN 既有門檻）。
5. 能被找到：Google 搜「{卡名} 日文」「{系列名} 卡表」這類詞時有機會出現；分享連結有正確的預覽圖。
6. 值得信任：有隱私說明、聯絡方式、資料來源頁。

**不做：** 登入與雲端收藏、廣告與聯盟連結（問題 25）、使用者行為追蹤、新的價格來源、開包特效、打包工具或前端框架、任何付費服務（除非使用者在決定 1 同意）。

第 1 波和第 3 波可以同時進行（一個在 main、一個在分支），但第 3 波每個階段開始前要先把 main 併進分支。

**同一時間每個檔案只給一個 worker。** 第 1 波建議這樣分，四個 worker 可以平行：

| worker | 工作包 | 獨占的檔案 |
|---|---|---|
| W1 伺服器 | A1 → A2 → F1（伺服器部分）→ F2 → F3（接圖） | `server.mjs`、`providers/seo.mjs`、`test/rate-limit*`、`test/server-hardening*`、`test/seo*` |
| W2 前端 | A3 → B1 → B2（前端部分）→ B3 → B4 → B5a → B5b → F1（兩個 h1 改 h2）→ D1 先修的那一點 | `index.html`、`ui-enhancements.js`、`series-band.js`、`price-*.js`、`market-events.js`、`look-showcase.js`、`navigation-state.js`、所有 `.css` |
| W3 設定 | A4 → A6 → B5 → A5 | `package.json`、`.github/`、`manifest.webmanifest`、`sw.js`、`test/pwa*`、`scripts/preview-proxy.mjs` |
| W4 內容 | G1 → G3 → G4 → F3（做圖）→ C1 | `docs/`、`assets/brand/web/` 的新圖；G1、G3 要放進頁面的文字交給 W2 排在 B4 後面插入 |

B2 的伺服器端標題由 W1 做，前端由 W2 做，兩邊用同一份文案（Opus 先定好再發包）。

**每個工作包的完成條件（共通）：**
1. `node --test` 全過（目前基準約 725；改到文字比對測試要一併更新）。
2. `npm run check` 過（A4 之後）。
3. 前端改動：本機預覽桌機 1440×900 與手機 375×812 各截一張；鍵盤走一遍；「暫停動態」開著時正常。
4. 上線後在正式站重看一次，不是只看本機。
5. 更新 `docs/AGENT_BATON.md`，commit 並 push。
6. worker 回報要分開寫「驗證過的」與「沒驗證的」。Opus 抽查 diff，不照單全收。

**給 Opus 的注意事項：**
- 開工先讀 `docs/AGENT_BATON.md`，不要整份讀 `docs/HANDOFF.md`。
- 本機有未提交的 `look-next.css`、`look-next.js` 與 `index.html` 的兩行改動，是預覽稿，不要提交到 main。

## 7. 風險

- **重新設計的分支活太久。** main 的小修要常併進去；第 1 波的 B 系列在 E 階段 3、4 會被重寫一部分，所以 B 只修「現在就誤導使用者」的，其餘留給 E。
- **搬家換網址。** 沒有自己的網域就搬，等於重新開站。所以決定 1、2 綁在一起。
- **資料庫只剩約 80 MB。** F4 每天一列沒問題；任何新資料表都要先估大小。
- **免費方案的條件。** Render 免費時數只夠一個服務（搬家時新舊並存不能超過幾天）；價格來源限非商業。
- **第 1 節有兩條沒查到底**（問題 2 的跳脫是否齊全、問題 8 的原因），工作包 A3、B3 的第一步就是查清楚，結果可能讓工作量變大或變成不用做。
- **W2 的隊伍很長**（九個包都排在同一個 worker），因為前端幾乎所有功能都擠在 `index.html` 與 `ui-enhancements.js`。Opus 可以在 W2 做完 A3 後另開第二個前端 worker 只做 CSS 類的包，前提是兩邊不碰同一個檔案。
